# 附录 A 常用指令模板

## A.0 先学写指令，再抄模板

模板解决的是「常见场景」，但真实工作千变万化。掌握指令的基本结构，比收藏一百条模板更有用。

一条完整的任务指令通常包含五个要素：

| 要素 | 说明 | 示例 |
|------|------|------|
| 动作 | 要它做什么 | 汇总、对比、改写、生成 |
| 对象 | 对什么做 | `@Q2销售数据.csv`、当前文件夹 |
| 约束 | 边界和规则 | 只看华东区、按月份分组 |
| 输出 | 交付成什么样 | 一个 Excel、一张表、三页 Word |
| 落点 | 结果放哪里 | 保存到 `~/reports/` 目录 |

对照感受一下：

```text
❌ 模糊：帮我分析一下这个数据。

✅ 完整：读取 @Q2销售数据.csv，按月份汇总华东区的销售额，
找出同比增长最快的 3 个产品，生成一张对比表，
保存到 ~/reports/Q2_华东区分析.xlsx。
```

模糊的指令会让 AI 来回反问或自行猜测，多轮往返既慢又容易跑偏；要素齐全的指令往往一次就能交付。

养成三个进阶习惯：

1. **先出方案再动手**：涉及批量移动、删除、改名时，加一句「先给我方案，我确认后再执行」，把风险拦在执行前。
2. **要求它自我验证**：交付涉及具体数字或格式时，加一句「完成后检查一遍，把实际的页数/行数/文件大小告诉我」，避免「说完成≠真完成」。
3. **在原指令上迭代**：结果不满意时直接追加「更简洁一些」「第三部分重写」，不要清空重来——上下文里已经有的信息会被浪费。

发出指令前，花十秒钟自查：动作说了吗？对象给了吗？约束讲了吗？输出定了吗？落点指了吗？五个都齐了再发。

## A.1 文件整理

```text
请整理当前文件夹中的文件。
按文件类型和主题分类，生成新的文件夹结构。
在执行前先给我一个整理方案，不要直接移动文件。
```

## A.2 Excel 分析

```text
请分析这个 Excel 文件。
请输出：核心指标、异常数据、趋势变化、可能原因、建议行动。
请生成一个摘要报告和图表。
```

## A.3 PPT 生成

```text
请根据这份 Word 文档生成一份 PPT 大纲。
要求：10 页左右，每页包含标题、3-4 个要点和建议图表。
风格正式，适合管理层汇报。
```

## A.4 会议纪要

```text
请整理这段会议内容。
输出：会议结论、待办事项、负责人、截止时间、风险点、未决问题。
```

## A.5 行业调研

```text
请调研【行业/公司/产品】。
输出：市场背景、主要玩家、竞品对比、趋势判断、机会点、风险点。
请附上信息来源链接。
```

## A.6 销售方案

```text
请基于客户资料生成一份售前方案。
包括：客户背景、痛点分析、推荐场景、实施路径、预期收益、演示流程。
```

## A.7 批量重命名

```text
请把当前文件夹里所有截图按「主题_序号」重命名。
先列出重命名对照表（旧文件名 → 新文件名），我确认后再执行。
```

## A.8 文章速读笔记

```text
请阅读这篇文章并输出笔记：【粘贴正文】
结构：核心观点（100 字以内）+ 3-5 条要点（每条一句话）+ 1 条可执行建议。
保存为 Markdown 文件到「知识库」文件夹，文件名「日期_标题.md」。
```

## A.9 周报汇总

```text
请根据本周的聊天记录和文档，整理一份周报。
分「本周完成 / 进行中 / 下周计划 / 风险与求助」四部分，
每部分不超过 5 条，输出为 Word 文档保存到桌面。
```
