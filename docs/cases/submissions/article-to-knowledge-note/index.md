# 把公众号好文搬进本地知识库：用 WorkBuddy 自动生成带标签的 Markdown 笔记

> 提交前，请先搜索社区案例集和蓝皮书，确认场景或任务没有重复。如果只是补充或优化已有方法，请优先修改原案例。

## 场景描述

公众号是很多人日常信息摄入的主渠道，但好文章的命运往往是：顺手点个收藏，然后永远不再打开。收藏夹越堆越高，真正消化吸收的几乎没有。

社区案例里已有「ima + WorkBuddy」的知识管理方案，那条路线依赖腾讯 ima 平台做存储。而很多人的笔记都在本地（比如 Obsidian、Logseq 这类 Markdown 知识库），不希望内容再经过第三方云平台。

这条 Case 走的是**纯本地路线**：让 WorkBuddy 把一篇公众号文章直接加工成一篇结构统一、带标签的 Markdown 笔记，写进你指定的本地文件夹。笔记格式统一，之后用 Obsidian 打开就是一座可搜索、可双链的知识库。

## 想要完成的任务

- 输入：一篇公众号文章的正文（复制粘贴），或文章链接。
- 目标：AI 自动完成「提炼 → 打标签 → 按模板排版 → 写入指定文件夹」全流程，而不是只输出一段聊天回复。
- 预期交付物：本地知识库文件夹里多出一篇命名规范、带 YAML 信息头（标题/来源/链接/日期/标签）的 Markdown 笔记。

## 使用的 Skill

| Skill | 用途 | 来源或安装方式 |
| --- | --- | --- |
| 文件操作 | 在知识库文件夹中新建、写入 Markdown 笔记 | WorkBuddy 内置 |
| 网页读取 | 输入为链接时抓取文章正文（可选，粘贴正文则不需要） | WorkBuddy 内置 |

## 前置条件

- WorkBuddy 版本：任意支持文件夹授权的版本
- 操作系统：Windows 10+ / macOS 12+
- 所需账号或权限：在「设置 → 安全中心 → 文件夹授权」中授权你的知识库文件夹
- 所需输入文件：无（文章正文直接粘贴进对话框即可）

## 在 WorkBuddy 中的操作

1. 在本地建好知识库文件夹（例如 `D:\KnowledgeBase\知识`），并在 WorkBuddy 中完成文件夹授权。
2. 复制想收藏的公众号文章全文，粘贴到 WorkBuddy 对话框。
3. 把下方「任务指令」中的要求一并发出（正文附在指令后面）。
4. 检查生成的笔记文件：文件名、信息头、标签是否符合约定。
5. 用 Obsidian（或任意 Markdown 编辑器）打开该文件夹，确认笔记正常显示、标签可被检索。

## 提示词或任务指令

```text
请把下面的文章整理成一篇知识库笔记，要求：

1. 在已授权的「知识」文件夹下新建 Markdown 文件，
   文件名为「今天日期_文章标题.md」，日期格式 YYYY-MM-DD，
   自动去掉文件名中的非法字符。
2. 文件开头写入 YAML 信息头，字段包括：
   title（文章标题）、source（来源公众号/作者）、url（原文链接，没有就留空）、
   created（今天日期）、tags（3-5 个中文标签）。
3. 正文分三个小节：
   - 「核心观点」：100 字以内；
   - 「要点提炼」：3-7 条，每条一句话，保留关键数据和结论；
   - 「我的行动」：基于文章内容给出 1-3 条可执行的建议。
4. 写完后汇报：文件保存路径、文件名字、生成的标签。

文章正文如下：
【在这里粘贴文章全文】
```

## 在 WorkBuddy 中的效果

执行完成后，知识库文件夹中新增一篇格式统一的笔记，例如 `2026-07-31_为什么你的收藏夹一直在吃灰.md`，开头是规范的 YAML 信息头，正文三个小节齐全。在 Obsidian 中打开库文件夹，新笔记出现在文件列表，标签面板里能直接按标签聚合检索。

## 验收标准

- 笔记文件真实存在于授权的知识库文件夹中，文件名符合「日期_标题.md」约定。
- YAML 信息头五个字段齐全，标签数量为 3-5 个。
- 「核心观点」不超过 100 字，「要点提炼」保留了原文关键数据。
- 连续处理 3 篇不同主题的文章，三篇笔记结构完全一致（验证模板稳定性）。

## 遇到的问题

- **直接发文章链接抓取失败**：部分公众号文章有反爬限制，网页读取拿不到正文。解决办法：改为在浏览器里全选复制正文，粘贴给 WorkBuddy，成功率接近 100%。
- **文件名报错**：文章标题常含 `《》？：` 等字符，Windows 下部分符号不能用于文件名。在指令里明确「自动去掉非法字符」后不再出现。
- **标签越攒越乱**：自由打标签容易出现「AI」「人工智能」并存。进阶做法是在知识库里维护一个标签清单文件，指令中要求 WorkBuddy 优先从清单中选标签。

## 安全与限制

- 笔记仅用于个人学习，原文版权归原作者所有；不要在笔记库中全文转发或二次发布他人文章。
- 文件夹授权只开放知识库目录，不要图省事直接授权整个磁盘。
- AI 提炼可能有遗漏或误读，涉及投资决策、医疗建议等内容时请回读原文核对。

## 可以怎样复用

- **抖音/视频文案**：把视频文案文字粘贴进来，同一模板直接套用，「来源」字段填作者名。
- **会议纪要**：把「我的行动」小节改名「待办事项」，增加负责人和截止时间要求。
- **群聊精华**：把聊天导出文本去隐私后粘贴，让它提炼「讨论结论 + 分歧点」。
- 核心思路不变：**一次把格式约定说清楚，之后每篇内容都走同一条流水线**，知识库才不会变成第二个收藏夹。
